# LegitClient — Fabric 1.21.4

Open **Actions** after pushing this project. The workflow builds the mod with Java 21 and uploads the JAR as an artifact.

1. Open the repository's **Actions** tab.
2. Select **Build Fabric mod** and click **Run workflow**.
3. Open the completed run and download **LegitClient-Fabric-1.21.4**.
4. Extract the downloaded ZIP; the JAR is inside.
5. Install Fabric Loader and Fabric API for Minecraft 1.21.4, then put the JAR in .minecraft/mods.
6. Launch the Fabric profile and press **Right Shift**.

Current modules are GUI toggles only; they do not automate combat or bypass anti-cheat.
